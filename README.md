## ⚙️ Algorithm Analysis

Understanding performance is an essential part of writing effective algorithms.

I practise evaluating solutions using:

- **Time Complexity:** Measuring how execution time grows with input size.
- **Space Complexity:** Understanding additional memory requirements.
- **Big-O Notation:** Describing algorithmic growth rates.
- **Optimization:** Comparing alternative approaches to the same problem.
- **Trade-offs:** Evaluating the balance between execution efficiency and memory consumption.

## 🧩 How I Approach a DSA Problem

My problem-solving workflow follows a structured process:

1. **Problem Decomposition** – Identify the inputs, outputs, constraints and expected behaviour.
2. **Approach Selection** – Explore suitable data structures and algorithmic techniques.
3. **Solution Development** – Translate the selected approach into Python.
4. **Correctness Validation** – Test normal cases, boundary conditions and edge cases.
5. **Complexity Evaluation** – Examine time and auxiliary space complexity.
6. **Solution Refinement** – Explore whether a more efficient or maintainable approach exists.
